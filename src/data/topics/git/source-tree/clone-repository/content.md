# Clone a repository with Sourcetree

1. Copy the HTTPS or SSH repository URL.
2. Open **Clone** in Sourcetree.
3. Paste the URL into **Source Path / URL**.
4. Choose a destination and click **Clone**.
5. Confirm the working copy is on the expected default branch.

```bash
git clone https://github.com/Yash-777/CodeTrove.git
```
