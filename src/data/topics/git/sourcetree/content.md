# Sourcetree

Sourcetree is a visual Git client designed to make branching, commit inspection, merges, and pull requests easier for developers who prefer a guided workflow.

## Why teams use it

- Easier branch inspection
- Visual commit history
- Drag-and-drop merge workflows
- Faster onboarding for new Git users

## Common workflow

1. Clone the repository
2. Create a feature branch
3. Commit changes
4. Push the branch
5. Open a pull request
6. Merge and delete the branch

## Best practice

Use Sourcetree as a visual layer on top of Git, not as a replacement for understanding Git fundamentals.
