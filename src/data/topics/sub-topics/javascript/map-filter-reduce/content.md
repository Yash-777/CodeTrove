# JavaScript Array Methods

Array methods are small, composable building blocks for transforming and inspecting collections.

- **map** creates a new array with one result per item.
- **filter** creates a new array containing matching items.
- **reduce** combines the array into one result.

See the [MDN Array reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array) for the complete API.
