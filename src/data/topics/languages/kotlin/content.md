# Kotlin

Kotlin is a modern, concise, statically typed language commonly used for JVM and Android development.

## Try it

Every example marked with **Run** is a live Kotlin editor. Edit the code and press **Run** (or `Ctrl/Cmd + Enter`). Compiler errors are underlined while you type.

```kotlin runnable
fun main() {
    println("Hello, Kotlin!")
}
```

> [!NOTE]
> Kotlin code is compiled on JetBrains' public compiler service (`api.kotlinlang.org`, the backend of [play.kotlinlang.org](https://play.kotlinlang.org)), so Kotlin boxes need an internet connection and send the snippet text to that service.
