# Email Overview

**Des:** Electronic mail (email) is a method of transmitting and receiving digital messages using electronic devices over a computer network. It allows users to send text, attachments, and media across the internet in a fast and reliable way.

## How email works

An email message is sent from a sender's mail client to a mail server, then forwarded to the recipient's server and finally delivered to the inbox. The process depends on standard protocols such as SMTP, IMAP, and POP3.

## Common email concepts

- **Protocol**: A set of rules that defines how email is sent and received.
  - SMTP: Used to send emails
  - IMAP: Used to receive and sync emails from the server
  - POP3: Used to download emails from the server
- **Port**: A network port used by the mail server.
  - SMTP: 25, 465, 587
  - IMAP: 143, 993
  - POP3: 110, 995
- **Host**: The mail server address or hostname, such as `smtp.gmail.com` or `imap.gmail.com`
- **Domain**: The email domain, such as `gmail.com`, `outlook.com`, or `company.com`
- **Username / mailbox**: The account name or email address used to log in
- **Authentication**: Verifying the sender using username and password, or app passwords / OAuth tokens

## Example email address

`name@example.com`

- `name` = mailbox/user name
- `@` = separator
- `example.com` = domain name

## Quick summary

Email is one of the most important communication tools on the internet. It uses standard mail protocols, server hosts, domain names, and ports to deliver messages securely and consistently between users and systems.
